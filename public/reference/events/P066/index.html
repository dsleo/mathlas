1847 · Logic & foundations

Boolean algebra: logic as algebra, then topology (Boole to Stone)

Propositional logic is treated as an algebra, and Stone's theorem gives a topological dictionary for it, anticipating duality methods in logic and model theory.

  2. 1847

    Boole applies algebraic calculation to logic

    first application

    G. Boole, The Mathematical Analysis of Logic (Cambridge, 1847)

    Boole deliberately uses algebraic operations to solve problems of logical inference.

    Dating or attribution note

    The 1847 book truly plays both roles: it states the algebra of logic and applies calculation to logical inference. Stone’s 1934 topological application remains a separate milestone in the Stone phase.
