1944 · Probability

Ito calculus and stochastic differential equations

A differential and integral calculus for Brownian paths is built and used to solve stochastic differential equations.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1923

    Wiener's path-space measure

    precursor

    Wiener, N., Differential-space, J. Math. Phys. 2 (1923) 131-174, zbMATH 49.0412.10

    Wiener defines measures on path space and integrates along Brownian paths, the analytic base that Ito later used.

    Evidence (2)
    • zbMATH record: 'Differential-space', J. Math. Phys. 2 (1923) zbMATH API (Zbl 49.0412.10)
    • MacTutor: in 1923 Wiener defined probability measures in path spaces, using Lebesgue integrals MacTutor Biography: Kiyosi Ito
  2. 1942

    Ito's theory of stochastic processes

    precursor

    Ito, K., On stochastic processes I (Infinitely divisible laws of probability), Japanese J. Math. 18 (1942) 261-301, zbMATH 0060.28908

    Ito's earlier study of stochastic processes, from which the integral and equations were developed; it is not the integral itself.

    Evidence (2)
    • zbMATH record: 'On stochastic processes. I', Jap. J. Math. 18 (1942) zbMATH API (Zbl 0060.28908)
    • MacTutor: Ito's famous 1942 paper on stochastic processes MacTutor Biography: Kiyosi Ito
  3. 1944

    Ito's stochastic integral

    first statement

    Ito, K., Stochastic integral, Proc. Imp. Acad. Tokyo 20 (1944) 519-524, doi 10.3792/pia/1195572786

    Defines a stochastic integral against Brownian motion, the central concept of Ito calculus.

    Evidence (3)
    • Crossref record: 'Stochastic integral', Proc. Imp. Acad. Tokyo, 1944 Crossref API
    • zbMATH record: 'Stochastic integral', 1944 zbMATH API (Zbl 0060.29105)
    • Wikipedia: the central concept is the Ito stochastic integral Wikipedia: Ito calculus
  4. 1946

    Ito's stochastic integral equation

    first application

    Ito, K., On a stochastic integral equation, Proc. Japan Acad. 22 (1946) 32-35, doi 10.2183/pjab1945.22.32

    Applies the stochastic integral to solve a stochastic integral equation, the first use on a target problem.

    Dating or attribution note

    Content inferred from the title; not read in full.

    Evidence (2)
    • Crossref record: 'On a stochastic integral equation', Proc. Japan Acad., 1946 Crossref API
    • zbMATH record: 'On a stochastic integral equation', 1946 zbMATH API (Zbl 0063.02992)
  5. 1951

    Ito's stochastic differential equations memoir

    key development

    Ito, K., On stochastic differential equations, Mem. Amer. Math. Soc. 4 (1951), doi 10.1090/memo/0004

    Systematic theory of stochastic differential equations driven by Brownian motion.

    Evidence (2)
    • Crossref record: 'On stochastic differential equations', Mem. AMS, 1951 Crossref API
    • MacTutor: Ito devised stochastic differential equations after solitary endeavours MacTutor Biography: Kiyosi Ito
  6. 1969

    McKean's monograph on stochastic integrals

    consolidation

    McKean, H. P., Stochastic integrals, Academic Press (1969), zbMATH 0191.46603

    A monograph devoted to stochastic integrals, consolidating the Ito calculus into a textbook treatment.

    Evidence (1)
    • zbMATH record: 'Stochastic integrals', Academic Press 1969 zbMATH API (Zbl 0191.46603)
