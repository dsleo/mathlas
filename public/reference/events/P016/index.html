1939 · Number theory

Weil's dictionary: number fields, function fields, Riemann surfaces

A three-way analogy between number fields, function fields over finite fields and compact Riemann surfaces transfers statements and methods between arithmetic and geometry.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1882

    Dedekind-Weber algebraic functions

    precursor

    Dedekind and Weber, Theorie der algebraischen Functionen einer Veraenderlichen, Crelle 92, 181-290, 1882

    They treated algebraic functions by the same ideal-theoretic means as number fields.

    Dating or attribution note

    Content not read; claim based on the standard account.

    Evidence (1)
    • Record: Crelle 92 (1882) 181-290. Crossref
  2. 1924

    Artin on quadratic function fields

    precursor

    Artin, Quadratische Koerper im Gebiete der hoeheren Kongruenzen, Math. Z. 19, 153-206, 1924

    Artin formulated the zeta function of function fields over finite fields with its Riemann hypothesis.

    Dating or attribution note

    Content not read. Reclassified from key_development to precursor: it predates this event's first statement (1939) and belongs to the wider field.

    Evidence (1)
    • Record: Math. Z. 19 (1924) 153-206. Crossref
  3. 1939

    Weil on the number field/function field analogy

    first statement

    Weil, Sur l'analogie entre les corps de nombres algebriques et les corps de fonctions algebriques, 1939

    Weil stated the analogy explicitly.

    Evidence (2)
    • Record in Oeuvres Scientifiques (1979 reprint). Crossref
    • zbMATH 65.1140.01: Weil, 'Sur l'analogie entre les corps de nombres algebriques et les corps de fonctions algebriques', dated 1939, pp. 104-106. zbMATH Open, document 65.1140.01
  4. 1940

    Weil on algebraic functions with finite constant field

    first application

    Weil, Sur les fonctions algebriques a corps de constantes fini, C. R. Acad. Sci. 210, 1940

    Weil announced a proof of the Riemann hypothesis for curves using geometry on the curve.

    Evidence (2)
    • Oeuvres reprint record. Crossref
    • Says he proved the Riemann hypothesis for curves over finite fields while in prison. MacTutor biography of Weil
  5. 1949

    Weil conjectures

    key development

    Weil, Numbers of solutions of equations in finite fields, Bull. AMS 55, 497-508, 1949

    Weil stated conjectures for zeta functions of varieties.

    Evidence (2)
    • Record: 1949. Crossref
    • Says in 1949 he raised these conjectures. MacTutor biography of Weil
  6. 1960

    Dwork proves rationality of the zeta function

    key development

    B. Dwork, On the rationality of the zeta function of an algebraic variety, Amer. J. Math. 82 (1960)

    Dwork proves the rationality part of the Weil conjectures by p-adic methods.

    Evidence (1)
    • zbMATH record: Dwork, On the rationality of the zeta function of an algebraic variety, Am. J. Math. 82, 1960. zbMATH record 0173.48501
  7. 1967

    Weil's 'Basic number theory' treating number fields and function fields together

    consolidation

    A. Weil, Basic Number Theory, Die Grundlehren der math. Wiss. 144, Berlin-Heidelberg-New York: Springer, 1967

    A monograph that treats local and global fields in a single framework, covering both number fields and function fields.

    Dating or attribution note

    Scope taken from the title and series; the book's chapter content was not read. Weil's 1939 analogy note is already the first_statement in the record.

    Evidence (1)
    • zbMATH record 'Basic number theory', Weil, Grundlehren 144 (1967), Zbl 0176.33601 zbMATH Open API
  8. 1974

    Deligne proves the last Weil conjecture

    key development

    Deligne, La conjecture de Weil I, Publ. IHES 43, 273-307, 1974

    Deligne proved the analogue of the Riemann hypothesis.

    Evidence (2)
    • Record: 1974. Crossref
    • Says the analogue of the Riemann hypothesis was proved by Deligne. Wikipedia: Weil conjectures
