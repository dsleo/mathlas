Axiomatic set theory (Zermelo)

Zermelo proved well-ordering from choice and axiomatized set theory.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1902

    Russell's paradox found in set theory

    precursor

    The paradox that Zermelo found independently of Russell motivates the axiomatic response.

    Evidence (1)
    • Russell found the ultimate paradox in 1902 and Zermelo found it independently MacTutor, Beginnings of set theory (saved page)
  2. 1904

    Well-ordering theorem from choice

    precursor

    Zermelo, E., 'Beweis, dass jede Menge wohlgeordnet werden kann', Math. Ann. 59 (1904)

    Zermelo proves that every set can be well-ordered by using the axiom of choice, a key step toward the axiomatisation.

    Evidence (1)
    • Crossref record: Mathematische Annalen, year 1904 Crossref, DOI 10.1007/bf01445300
  3. 1908

    Zermelo's axiomatic set theory

    first statement

    Zermelo, E., 'Untersuchungen über die Grundlagen der Mengenlehre I', Math. Ann. 65 (1908)

    Zermelo gives the first axiomatisation of set theory, avoiding the paradoxes.

    Evidence (2)
    • Crossref record: Mathematische Annalen, year 1908 Crossref, DOI 10.1007/bf01449999
    • zbMATH record: 'Untersuchungen über die Grundlagen der Mengenlehre I', year 1908 zbMATH API, query 'Zermelo Untersuchungen uber die Grundlagen der Mengenlehre I'
  4. 1922

    Fraenkel on Cantor-Zermelo set theory

    key development

    A. Fraenkel, Zu den Grundlagen der Cantor-Zermeloschen Mengenlehre, Math. Ann. 86 (1922)

    Fraenkel sharpens the definite-property axiom and adds replacement, yielding the Zermelo-Fraenkel system.

    Dating or attribution note

    The mention of replacement is recalled from standard history and not read.

    Evidence (1)
    • Crossref record: Fraenkel, Zu den Grundlagen der Cantor-Zermeloschen Mengenlehre, Math. Ann., 1922. Crossref, DOI 10.1007/bf01457986
  5. 1923

    Skolem's remarks on the axiomatic foundation

    key development

    T. Skolem, Einige Bemerkungen zur axiomatischen Begründung der Mengenlehre, Helsingfors 1923

    Skolem proposes first-order formulation of the axioms and independently suggests replacement.

    Evidence (1)
    • Jahrbuch record: Skolem, Einige Bemerkungen zur axiomatischen Begründung der Mengenlehre, 1923. zbMATH record 49.0138.02
  6. 1923

    von Neumann on transfinite numbers

    key development

    J. von Neumann, Zur Einführung der transfiniten Zahlen, Acta Szeged 1 (1923)

    Defines ordinals as sets, using replacement.

    Evidence (1)
    • Jahrbuch record: von Neumann, Zur Einführung der transfiniten Zahlen, Acta Szeged 1, 1923. zbMATH record 49.0139.02
  7. 1930

    Zermelo on limit numbers and set domains

    key development

    E. Zermelo, Über Grenzzahlen und Mengenbereiche, Fund. Math. 16 (1930)

    Zermelo adds foundation and replacement and describes the cumulative hierarchy.

    Evidence (1)
    • Crossref record: Zermelo, Über Grenzzahlen und Mengenbereiche, Fundamenta Mathematicae, 1930. Crossref, DOI 10.4064/fm-16-1-29-47
  8. 1937

    Bernays, 'A system of axiomatic set theory. I'

    naming

    P. Bernays, 'A system of axiomatic set theory. I', Journal of Symbolic Logic, pages 65-77, zbMATH record 3031148, 1937

    Bernays's 1937 paper is the earliest title in the searched window that uses the phrase 'axiomatic set theory' for the field.

    Evidence (1)
    • zbMATH record gives title 'A system of axiomatic set theory. I', author P. Bernays, year 1937, journal article, pages 65-77, in a journal with ISSN 0022-4812 zbMATH Open API, document 3031148
