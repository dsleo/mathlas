1750 · Differential equations

Vibrating-string controversy and the general function concept

The dispute between d'Alembert and Euler over admissible initial shapes pushed analysis from formulas toward arbitrary dependence, later made explicit in Euler's definition and Fourier's heat work.

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1694

    Johann Bernoulli's definition of a function

    precursor

    J. Bernoulli, letter to Leibniz, 2 September 1694

    Bernoulli calls a function a quantity formed in any way from variable and constant quantities; Leibniz approves the term.

    Evidence (1)
    • Johann Bernoulli described a function in a letter of 1694; 'functions of ordinates' appears in an 1698 paper; Leibniz approved MacTutor, The function concept
  2. 1749

    D'Alembert requires an analytic initial shape

    precursor

    d'Alembert, Histoire de l'Académie de Berlin 3 (dated 1747, printed c. 1749)

    D'Alembert insists the initial data of a vibrating string be given by a single analytic expression.

    Evidence (2)
    • D'Alembert insisted the initial velocities be one analytic expression MacTutor, The function concept
    • Cites the 1747 Berlin memoirs on the vibrating string Wikipedia, Jean le Rond d'Alembert
  3. 1750

    Euler argues for arbitrary initial curves

    first statement

    Euler, Sur la vibration des cordes, Mémoires de l'Académie de Berlin 4, 1750

    Euler objects that physics demands more general initial shapes than one analytic formula, the opening of the controversy on admissible functions.

    Evidence (2)
    • Euler published a paper in 1749 objecting to d'Alembert's restriction; the long controversy began MacTutor, The function concept
    • Euler Archive: Sur la vibration des cordes, printed 1750 Euler Archive record E140 (bepress metadata)
  4. 1755

    Euler's general definition of a function

    key development

    Euler, Institutiones calculi differentialis, St Petersburg, 1755

    Euler defines a function as any quantity depending on others in any way, a truly general definition, though the book then treats only analytic expressions.

    Evidence (2)
    • In 1755 Euler gave an entirely general definition MacTutor, The function concept
    • Catalogue entry, Institutiones calculi differentialis, 1755 Internet Archive catalogue record 10053431bsb
