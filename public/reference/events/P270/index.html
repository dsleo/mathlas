1935 · Numerical analysis

Kantorovich's functional analysis for numerical methods

Ordered vector spaces and normed spaces were applied to approximation and equation solving.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1935

    Kantorovich: semi-ordered linear spaces (K-spaces)

    first statement

    Kantorovich defined a new type of ordered linear space, now called a K-space, which became the basis for applying ordered spaces to analysis.

    Evidence (1)
    • MacTutor says Kantorovich defined K-spaces in 1935 MacTutor, Kantorovich biography
  2. 1936

    Semi-ordered spaces applied to numerical methods

    first application

    Kantorovich applied semi-ordered spaces to numerical methods, the first purposeful use of the functional-analytic idea for approximation.

    Evidence (1)
    • MacTutor says the 1936 paper On one class of functional equations applied semi-ordered spaces to numerical methods MacTutor, Kantorovich biography
  3. 1948

    Newton-Kantorovich theorem on Newton's method

    key development

    A semi-local convergence theorem for Newton's method, the functional-analytic result for which Kantorovich is best known in numerical analysis.

    Evidence (1)
    • Wikipedia says the Kantorovich theorem was first stated by Kantorovich in 1948 Wikipedia, Kantorovich theorem
  4. 1964

    Kantorovich, Functional Analysis in Normed Spaces (English edition)

    consolidation

    Kantorovich L. V., Akilov G. P., Functional Analysis in Normed Spaces, Pergamon Press, 1964 (English edition)

    The English edition of the main textbook on functional analysis in normed spaces and its numerical applications.

    Evidence (1)
    • Open Library record: Pergamon Press, 1964 Open Library
