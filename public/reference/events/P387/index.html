1899 · Logic & foundations

Axiomatisation of geometry

Hilbert gave a complete independent axiom system for Euclidean geometry that did not rely on diagrams, and used models to test independence.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1882

    Pasch's rigorous projective geometry

    precursor

    Pasch, M., Vorlesungen über neuere Geometrie, Leipzig (1882)

    Pasch's earlier rigorous treatment of geometry without relying on diagrams is a direct predecessor.

    Evidence (1)
    • zbMATH record: 'Vorlesungen über neuere Geometrie', year 1882 zbMATH API, query 'Pasch Vorlesungen uber neuere Geometrie'
  2. 1889

    Peano's logical axioms for geometry

    precursor

    Giuseppe Peano, I principii di geometria logicamente esposti, Turin, 1889

    Gives a symbolic axiom system for geometry with primitive notions, before Hilbert's book.

    Evidence (2)
    • I principii di geometria logicamente esposti, 1889, digitised record. Internet Archive record iprincipiidigeo01peangoog
    • Biography of Peano. MacTutor, Peano biography
  3. 1899

    Complete independent axiom system for Euclidean geometry

    first statement

    Hilbert, D., Grundlagen der Geometrie, Teubner, Leipzig (1899)

    Gives a 20-axiom system for Euclidean geometry, with independence proved by models.

    Evidence (2)
    • zbMATH record: 'Grundlagen der Geometrie', year 1899 zbMATH API, query 'Hilbert Grundlagen der Geometrie 1899'
    • Hilbert's axioms proposed in 1899 in Grundlagen der Geometrie; models used to prove independence Wikipedia, Hilbert's axioms (saved wikitext)
  4. 1904

    Veblen's system of axioms for geometry

    key development

    Oswald Veblen, A system of axioms for geometry, Trans. Amer. Math. Soc. 5, 343-384, 1904

    Gives a categorical axiom system for Euclidean geometry using order, in the style Hilbert opened.

    Evidence (2)
    • zbMATH record, Trans. AMS 5, 343-384 (1904). zbMATH 2653775
    • Veblen is named among the major contributors to the axiomatics of geometry. Wikipedia, Hilbert's axioms
  5. 1932

    Birkhoff's postulates based on scale and protractor

    key development

    George D. Birkhoff, A set of postulates for plane geometry, based on scale and protractor, Ann. of Math. 33, 1932

    Alternative axiomatisation that uses real-number measurement, later common in school geometry.

    Evidence (2)
    • Crossref record, Annals of Mathematics 33 (1932). Crossref 10.2307/1968336
    • Birkhoff's axiomatisation is named as another well-known one. Wikipedia, Hilbert's axioms
  6. 1968

    Later edition with supplements

    consolidation

    Hilbert, D., Grundlagen der Geometrie, 10th ed. with supplements by P. Bernays (1968)

    A later edition with supplements shows the 1899 system remained the standard text; it is not a first systematic treatment.

    Evidence (1)
    • zbMATH record for the 1968 edition with Bernays supplements zbMATH API, query 'Hilbert Grundlagen der Geometrie 1899'
