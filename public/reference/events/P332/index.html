1940 · Group & representation theory

Restricted Burnside problem

Zelmanov used Lie ring methods to show finitely many finite quotients exist for exponent n.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1933

    Levi and van der Waerden: B(m,3) is finite

    precursor

    Independent proof that the three-exponent Burnside group is finite, the earliest partial results on the restricted problem.

    Evidence (1)
    • MacTutor Burnside problem topic: in 1933 Levi and van der Waerden showed B(m,3) has finite order MacTutor Burnside problem topic
  2. 1940

    First paper on the restricted Burnside problem

    first statement

    O. Gruen, Zusammenhang zwischen Potenzbildung und Kommutatorbildung, J. reine angew. Math. 182 (1940), 158-177

    Gruen's paper is the first published work aimed at the restricted Burnside problem, which had circulated orally since the 1930s.

    Evidence (2)
    • The first paper addressing the restricted problem appeared in 1940 (Gruen); the problem was only present in seminars in the 1930s; the name came from Magnus in 1950. MacTutor, History of the Burnside problem
    • zbMATH lists the 1940 paper, J. reine angew. Math. 182, pp. 158-177. zbMATH Open document 2508900
  3. 1950

    Restricted Burnside problem term coined (Magnus)

    naming

    Magnus, A connection between the Baker-Hausdorff formula and a problem of Burnside, Ann. of Math. (1950)

    MacTutor says the term 'Restricted Burnside Problem' was coined by Magnus in 1950.

    Evidence (2)
    • zbMATH record for Magnus 1950 (Burnside problem) zbMATH
    • MacTutor Burnside problem topic: the term was coined by Magnus in 1950 MacTutor Burnside problem topic
  4. 1956

    Hall-Higman reduction theorem

    first application

    Hall and Higman, On the p-length of p-soluble groups and reduction theorems for Burnside's problem, Proc. London Math. Soc. (1956)

    A reduction theorem that reduces the restricted problem to prime-power exponents, the first purposeful use on the target problem.

    Evidence (2)
    • Crossref record: Hall and Higman, Proc. London Math. Soc., 1956 Crossref
    • MacTutor Burnside problem topic: the 1956 Hall-Higman paper contains a reduction theorem for the RBP MacTutor Burnside problem topic
  5. 1958

    Kostrikin: restricted problem for prime exponent

    key development

    Kostrikin, On Burnside's problem, Doklady Akad. Nauk SSSR 119 (1958) 1081-1084

    Kostrikin proves the restricted problem for prime exponent, the first complete solution for a class of exponents.

    Evidence (2)
    • zbMATH record: Kostrikin, On Burnside's problem, Dokl. Akad. Nauk SSSR 119 (1958) zbMATH
    • Wikipedia Burnside problem: Kostrikin proved in 1958 the restricted problem for prime exponent Wikipedia Burnside problem
  6. 1990

    Zelmanov: restricted problem for odd exponent

    key development

    Zelmanov, Solution of the restricted Burnside problem for groups of odd exponent, Izv. Akad. Nauk SSSR Ser. Mat. 54 (1990) 42-59

    Zelmanov solves the restricted problem for groups of odd exponent using Lie-ring methods.

    Evidence (1)
    • zbMATH record: Zelmanov, Solution of the restricted Burnside problem for groups of odd exponent, Izv. 54 (1990) zbMATH
  7. 1990

    Kostrikin's monograph Around Burnside

    consolidation

    Kostrikin, Around Burnside, Ergebnisse der Mathematik 20, Springer (1990)

    The first monograph on the Burnside problems, including the restricted case.

    Evidence (1)
    • zbMATH record: Around Burnside (Springer, Ergebnisse 20, 1990) zbMATH
  8. 1991

    Zelmanov: restricted problem for 2-groups

    key development

    Zelmanov, Solution of the restricted Burnside problem for 2-groups, Mat. Sb. 182 (1991) 568-592

    Completes the restricted problem for all exponents by treating the 2-group case.

    Evidence (1)
    • zbMATH record: Zelmanov, Solution of the restricted Burnside problem for 2-groups, Mat. Sb. 182 (1991) zbMATH
