Descriptive set theory

Baire, Lebesgue, Suslin and Lusin explored regularity of definable sets, leading to analytic and projective sets.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1899

    Baire's functions of a real variable

    precursor

    Baire, R., 'Sur les fonctions de variables réelles', Ann. Mat. Pura Appl. (1899)

    Baire's classes and his work on functions of real variables prepare the regularity questions of definable sets.

    Evidence (2)
    • zbMATH and Crossref record: 'Sur les fonctions de variables réelles', 1899 Crossref, DOI 10.1007/bf02419243
    • Baire, Sur les fonctions de variables reelles, Annali di Mat. (3) 3, 1-123 (1899) zbMATH Open id 2668286
  2. 1905

    Lebesgue's analytic functions and sets

    precursor

    Lebesgue, H., 'Sur les fonctions representables analytiquement', Journal de Mathematiques Pures et Appliquees (6) 1 (1905) 139-216

    Lebesgue treats the analytically representable functions and sets that lead to the analytic-set hierarchy.

    Evidence (2)
    • zbMATH record: 'Sur les fonctions représentables analytiquement', year 1905 zbMATH API, query 'Lebesgue Sur les fonctions representables analytiquement'
    • Lebesgue, Sur les fonctions representables analytiquement, J. Math. Pures Appl. (6) 1, 139-216 (1905) zbMATH Open id 2650533
  3. 1917

    Suslin's definition of analytic (B) sets

    first statement

    Suslin, M., 'Sur une définition des ensembles mesurables B sans nombres transfinis', C. R. Acad. Sci. (1917)

    Suslin gives a definition of the measurable B sets without transfinite numbers, the first explicit operation definition of analytic sets.

    Evidence (3)
    • zbMATH record: 'Sur une définition des ensembles mesurables B...', year 1917 zbMATH API, query 'Suslin Sur une definition des ensembles mesurables B'
    • Suslin's definition and its role in the analytic-set theory MacTutor, Suslin biography (live page)
    • Review: definition of the sets (A); a set is B-measurable iff it and its complement are (A); contradicts a claim of Lebesgue (1905) zbMATH Open id 2610533 (Souslin, C. R. 164, 88-91)
  4. 1917

    Lusin on Baire's classification: analytic sets are measurable

    key development

    Lusin, N., 'Sur la classification de M. Baire', C. R. Acad. Sci. 164 (1917) 91-94

    Lusin's note shows that every set (A) is Lebesgue measurable and reports Suslin's result that such a set contains a perfect subset or is at most countable.

    Evidence (1)
    • Review: every set (A) is Lebesgue measurable; Souslin: an (A) set contains a perfect subset or is at most countable zbMATH Open id 2610854 (Lusin, C. R. 164, 91-94)
  5. 1927

    Lusin: Sur les ensembles analytiques

    consolidation

    Lusin, N., 'Sur les ensembles analytiques', Fundamenta Mathematicae 10 (1927) 1-95

    A 95-page survey of the theory of analytic (Suslin) sets, the first systematic presentation in print found here.

    Evidence (1)
    • Review: a comprehensive presentation of analytic (Suslin, A) sets; chapters on Lebesgue's construction, B-measurability, sieves, projections zbMATH Open id 2581385 (Fund. Math. 10, 1-95)
  6. 1930

    Leçons sur les ensembles analytiques

    consolidation

    Lusin, N., Leçons sur les ensembles analytiques et leurs applications, Gauthier-Villars (1930)

    A systematic monograph treatment of analytic sets, the first book-length consolidation.

    Evidence (2)
    • zbMATH record: 'Leçons sur les ensembles analytiques', year 1930 zbMATH API, query 'Lusin Lecons sur les ensembles analytiques'
    • Review: monograph on the theory of analytic sets created by Lusin and Suslin zbMATH Open id 2562690
