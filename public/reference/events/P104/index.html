1935 · Analysis

Ahlfors' covering surfaces and value distribution

Nevanlinna's value distribution theory is given a topological and geometric proof through covering surfaces and length-area arguments.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1925

    Nevanlinna's value distribution theory

    precursor

    Nevanlinna, 'Zur Theorie der meromorphen Funktionen', Acta Mathematica 46 (1925)

    Nevanlinna's value distribution theory for meromorphic functions, the result Ahlfors reproved by covering surfaces.

    Evidence (1)
    • Nevanlinna theory devised in 1925 Wikipedia: Nevanlinna theory (lead)
  2. 1935

    Covering-surface proof of value distribution

    first statement

    Ahlfors, 'Zur Theorie der Uberlagerungsflachen', Acta Mathematica 65 (1935)

    Ahlfors gave a topological and geometric treatment of Nevanlinna's value distribution theory through covering surfaces.

    Evidence (2)
    • Paper record: Acta Math. 1935 (reprinted in Collected Papers 1982, with a 1997 commentary) Crossref
    • Ahlfors' covering-surface work is part of his 1930s output MacTutor: Ahlfors biography
  3. 1935

    Covering surfaces applied to value distribution

    first application

    Same paper: Ahlfors (1935)

    The covering-surface argument is applied to value distribution questions in the same paper.

    Dating or attribution note

    Same paper as the first_statement milestone (rule 2). Exact content of the 1935 paper, including any five-value result, was not checked in the text.

    Evidence (1)
    • Ahlfors' 1935 paper is the covering-surface treatment of value distribution Crossref record and commentary title
  4. 1964

    Hayman's Meromorphic Functions

    consolidation

    Hayman, Meromorphic Functions (Oxford: Clarendon Press, 1964)

    A systematic monograph on meromorphic functions, including value distribution.

    Evidence (1)
    • Open Library record: 'Meromorphic functions' by Hayman, first published 1964 Open Library search
