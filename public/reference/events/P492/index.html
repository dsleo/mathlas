≈ 2012 · Algebraic geometry

K-stability and Kahler-Einstein metrics on Fano manifolds

An algebraic-geometric stability condition is shown to be equivalent to existence of Kahler-Einstein metrics.

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 2012

    K-stability proof announced

    key development

    Kahler-Einstein metrics and stability (2012)

    The October public preprint announces and outlines a proof that K-stable Fano manifolds admit Kähler–Einstein metrics.

    Evidence (1)
    • The 28 October 2012 arXiv record says the authors announce the proof. Original repository record
  2. 2012

    Detailed cone-metric approximation paper

    key development

    Kahler-Einstein metrics on Fano manifolds, I: approximation of metrics with cone singularities (2012)

    The first detailed public preprint in the proof series develops cone-metric approximation.

    Evidence (1)
    • The dated publication record and abstract support the 2012 result. Original publication or repository record
  3. 2014

    Chen-Donaldson-Sun: cone-angle limits completing the KE existence proof

    key development

    Chen, X., Donaldson, S., Sun, S., Kähler-Einstein metrics on Fano manifolds III: limits as cone angle approaches 2π, JAMS (2014)

    Completes the cone-angle limit argument in the proof linking K-stability to Kähler-Einstein metrics on Fano manifolds.

    Evidence (1)
    • Crossref record, JAMS 2014 (online) Crossref
  4. 2014

    Székelyhidi's introduction to extremal Kähler metrics

    consolidation

    Székelyhidi, G., An Introduction to Extremal Kähler Metrics, AMS Graduate Studies in Mathematics 152 (2014)

    A graduate-level book introducing K-stability and extremal metrics as a textbook account.

    Evidence (2)
    • Crossref chapter record in GSM 152, 2014 Crossref
    • zbMATH record 'An introduction to extremal Kähler metrics', 2014 zbMATH Open API
