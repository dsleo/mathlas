2004 · Number theory

Green-Tao: primes contain long arithmetic progressions

Szemeredi's theorem is extended to a pseudorandom majorant via a transference principle, with sieve-theoretic input showing the primes sit inside one, using Gowers norms and ergodic-style structure theory.

Also known as: Green–Tao theorem

    first application

    B. Green and T. Tao, The primes contain arbitrarily long arithmetic progressions, arXiv:math/0404188 (2004)

  4. 2010

    Linear equations in primes

    key development

    Green, B.; Tao, T., Linear equations in primes, Ann. of Math. (2) 171 (2010) 1753-1850, DOI 10.4007/annals.2010.171.1753

    The transference method is extended from progressions to systems of linear equations in primes, giving the general framework that the 2004 result suggested.
