1950 · Information & cryptography

Algebraic coding theory

Error-correcting codes were built from algebra over finite fields.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1948

    Shannon's channel coding theorem

    precursor

    Shannon C. E., A mathematical theory of communication, Bell System Tech. J. 27, 1948

    Shannon showed that reliable communication is possible over a noisy channel, without a constructive algebraic code; the framework for coding theory.

    Evidence (1)
    • Crossref record: Bell System Tech. J. 27, 1948 Crossref
  2. 1950

    Hamming: error detecting and error correcting codes

    first statement

    Hamming R. W., Error detecting and error correcting codes, Bell System Tech. J. 29, 147-160, 1950

    Hamming introduced error-correcting linear codes over the binary field, the first explicit algebraic error-correcting construction in the public record checked.

    Evidence (2)
    • Crossref record: Bell System Tech. J. 29, 147-160, 1950 Crossref
    • MacTutor says the April 1950 paper started a new subject within information theory MacTutor, Richard Hamming biography
  3. 1960

    Reed and Solomon: polynomial codes over finite fields

    key development

    Reed I. S., Solomon G., Polynomial codes over certain finite fields, J. SIAM 8, 300-304, 1960

    Codes defined by polynomials over finite fields, giving the algebraic framework of Reed-Solomon codes.

    Evidence (1)
    • Crossref record: J. SIAM 8, 300-304, 1960 Crossref
  4. 1960

    Bose and Ray-Chaudhuri: binary group codes (BCH)

    key development

    Bose R. C., Ray-Chaudhuri D. K., On a class of error correcting binary group codes, Information and Control 3, 68-79, 1960

    A class of binary group codes built from finite-field algebra, now called BCH codes.

    Dating or attribution note

    Independent discovery by Hocquenghem (1959) is not checked here.

    Evidence (1)
    • Crossref record: Information and Control 3, 68-79, 1960 Crossref
  5. 1960

    Peterson: encoding and decoding procedures for BCH codes

    first application

    Peterson W. W., Encoding and error-correction procedures for the Bose-Chaudhuri codes, IRE Trans. Inf. Theory IT-6, 459-470, 1960

    Procedures for encoding and error correction in the Bose-Chaudhuri codes, a first purposeful use of the algebraic framework for decoding.

    Dating or attribution note

    Application claim rests on the title; content not checked.

    Evidence (1)
    • Crossref record: IRE Trans. IT-6, 459-470, 1960 Crossref
  6. 1961

    Peterson, Error-Correcting Codes

    consolidation

    Peterson W. W., Error-Correcting Codes, MIT Press and Wiley, 1961

    A book-length treatment of error-correcting codes, including the BCH theory.

    Evidence (1)
    • Open Library record: MIT Press and Wiley, 1961 Open Library
  7. 1968

    Berlekamp, Algebraic Coding Theory

    naming

    Berlekamp E. R., Algebraic Coding Theory, McGraw-Hill, 1968

    A book whose title uses the field name 'algebraic coding theory'.

    Evidence (1)
    • Open Library record: McGraw-Hill, 1968 Open Library
  8. 1977

    MacWilliams and Sloane, The Theory of Error-Correcting Codes

    consolidation

    MacWilliams F. J., Sloane N. J. A., The Theory of Error-Correcting Codes, North-Holland, 1977

    A standard monograph covering linear, BCH and Reed-Solomon codes.

    Evidence (1)
    • Open Library record: North-Holland, 1977 Open Library
