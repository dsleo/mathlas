Finite element method

Piecewise polynomial trial spaces gave systematic solvers.

Also known as: finite element analysis

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1941

    Hrennikoff's framework method

    precursor

    Hrennikoff, A., Solution of problems of elasticity by the framework method, J. Appl. Mech. 8 (1941), doi 10.1115/1.4009129

    A lattice or framework discretisation of elastic continua, an early discretisation idea that is not the element method.

    Evidence (2)
    • Crossref record: 'Solution of Problems of Elasticity by the Framework Method', J. Appl. Mech., 1941 Crossref API
    • Wikipedia: Hrennikoff discretises the domain by a lattice analogy Wikipedia: Finite element method, History
  2. 1943

    Courant's triangular variational method

    first statement

    Courant, R., Variational methods for the solution of problems of equilibrium and vibrations, Bull. Amer. Math. Soc. 49 (1943), doi 10.1090/s0002-9904-1943-07818-4

    Divides a domain into finite triangular sub-regions to solve elliptic problems by a variational method.

    Evidence (2)
    • Crossref record: 'Variational methods for the solution of problems of equilibrium and vibrations', BAMS, 1943 Crossref API
    • Wikipedia: Courant divides the domain into finite triangular sub-regions Wikipedia: Finite element method, History
  3. 1956

    Stiffness analysis of complex structures

    first application

    Turner, M. J., Clough, R. W., Martin, H. C., Topp, L. J., Stiffness and deflection analysis of complex structures, J. Aeronautical Sciences 23 (1956), doi 10.2514/8.3664

    Applies element stiffness matrices to analyse complex structures, a practical first use of the element method.

    Evidence (1)
    • Crossref record: 'Stiffness and Deflection Analysis of Complex Structures', J. Aeronautical Sciences, 1956 Crossref API
  4. 1967

    Zienkiewicz and Cheung's book

    consolidation

    Zienkiewicz, O. C., Cheung, Y. K., The finite element method in structural and continuum mechanics, McGraw-Hill (1967), zbMATH 0189.24902

    Book-length treatment of the element method across structural and continuum mechanics.

    Dating or attribution note

    Claim that this is the first systematic book is not verified; Zienkiewicz's earlier papers and other books were not checked.

    Evidence (2)
    • zbMATH record: 'The finite element method in structural and continuum mechanics', McGraw-Hill 1967 zbMATH API (Zbl 0189.24902)
    • Wikipedia: the method's development in the 1960s was driven by Zienkiewicz and co-workers Wikipedia: Finite element method, History
  5. 1973

    Strang and Fix: mathematical basis

    key development

    Strang, G., Fix, G. J., An Analysis of the Finite Element Method, Prentice-Hall (1973), zbMATH 0356.65096

    Gives the rigorous mathematical basis for the method, as the Wikipedia history states.

    Evidence (2)
    • zbMATH record: 'An analysis of the finite element method', Prentice-Hall 1973 zbMATH API (Zbl 0356.65096)
    • Wikipedia: a rigorous mathematical basis was provided in 1973 by Strang and Fix Wikipedia: Finite element method, History
