1959 · Logic & foundations

Kripke semantics (possible-world semantics for modal logic)

Relational models gave completeness theorems for modal logics.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1959

    Completeness theorem for modal logic via relational models

    first statement

    Kripke, A completeness theorem in modal logic, J. Symbolic Logic 24 (1959) 1-14

    Kripke proves completeness for modal systems with respect to relational (possible-world) models.

    Evidence (2)
    • Crossref record: A completeness theorem in modal logic, Journal of Symbolic Logic, 1959 Crossref
    • Wikipedia Saul Kripke: he wrote his first completeness theorem in modal logic and had it published a year later; his semantics is now called Kripke semantics Wikipedia Saul Kripke
  2. 1959

    Completeness proofs for modal systems

    first application

    Kripke, A completeness theorem in modal logic, J. Symbolic Logic 24 (1959)

    The same paper uses the relational models to prove completeness for particular modal systems, the first purposeful application.

    Evidence (1)
    • Crossref record for the 1959 paper (title names the completeness application) Crossref
  3. 1963

    Semantical analysis of normal modal propositional calculi

    key development

    Kripke, Semantical analysis of modal logic I: normal propositional calculi, Z. Math. Logik Grundlagen Math. 9 (1963) 67-96

    Systematic semantical analysis of normal modal calculi with frames and accessibility relations.

    Evidence (1)
    • Crossref record: Semantical Analysis of Modal Logic I, Mathematical Logic Quarterly, 1963 Crossref
  4. 1963

    Semantical considerations on modal logic

    key development

    Kripke, Semantical considerations on modal logic, Acta Philosophica Fennica 16 (1963) 83-94

    The informal account of the possible-world semantics, reaching a wider audience.

    Evidence (1)
    • zbMATH record: Semantical considerations on modal logic, Acta Philosophica Fennica 16, 1963 zbMATH
  5. 1968

    Textbook: An Introduction to Modal Logic

    consolidation

    Hughes and Cresswell, An Introduction to Modal Logic, Methuen (1968)

    First textbook treatment of modal logic with the relational semantics.

    Evidence (1)
    • Open Library record: An introduction to modal logic, Methuen, 1968 (G. E. Hughes) Open Library
