Cluster algebras

Mutation rules on seeds generate algebras whose combinatorics matches total positivity and canonical bases in Lie theory.

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 2001

    Cluster algebras introduced publicly

    first statement

    S. Fomin and A. Zelevinsky, Cluster algebras I: Foundations, arXiv:math/0104151 (2001)

    The preprint initiates a class of commutative algebras motivated by canonical bases and total positivity.

    Evidence (1)
    • ArXiv dates the public preprint to April 2001 and states the new class. Original publication or repository record
  2. 2003

    Cluster algebras II: finite type classification

    key development

    Fomin, S., Zelevinsky, A., Cluster algebras II: Finite type classification, Inventiones mathematicae (2003)

    Classifies the cluster algebras of finite type, the first large structural result on the theory.

    Evidence (1)
    • Crossref record, Inventiones (2003) Crossref
  3. 2003

    Fomin-Zelevinsky notes for CDM-03

    consolidation

    Fomin, S., Zelevinsky, A., Cluster algebras: Notes for the CDM-03 conference, Current Developments in Mathematics (2003)

    Expository notes presenting the core definitions and results of cluster algebras for a general mathematical audience.

    Evidence (1)
    • Crossref record, Current Developments in Mathematics (2003) Crossref
  4. 2008

    Cluster algebras and triangulated surfaces

    key development

    Fomin, S., Shapiro, M., Thurston, D., Cluster algebras and triangulated surfaces. Part I: Cluster complexes, Acta Mathematica (2008)

    Links cluster algebras to triangulated surfaces, giving a geometric model for a large class of them.

    Evidence (1)
    • Crossref record, Acta Math. (2008) Crossref
