1975 · Logic & foundations

Hilbert's tenth problem over rings of integers

The remaining cases of undecidability for Diophantine equations over rings of integers were settled using a specially built elliptic curve with quadratic twists and prime selection from additive combinatorics.

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1970

    Matiyasevich's theorem over Z

    precursor

    Matiyasevich, Yu. V., Enumerable sets are Diophantine, Doklady Akademii Nauk SSSR, 1970

    Solves Hilbert's tenth problem over the integers, the basis on which the number-field versions build.

    Evidence (2)
    • Enumerable sets are Diophantine, 1970 zbMATH record 3336816
    • Matiyasevich completed the MRDP theorem in 1970 Wikipedia, Hilbert's tenth problem
  2. 1975

    Undecidability for quadratic rings

    first statement

    Denef, J., Hilbert's tenth problem for quadratic rings, Proceedings of the American Mathematical Society, 1975

    The first published undecidability result for rings of integers of a restricted kind (quadratic rings).

    Evidence (2)
    • Hilbert's tenth problem for quadratic rings, Proc. AMS, 1975 Crossref record
    • Denef and Lipschitz's earlier work underlies the later number-field results Wikipedia, Hilbert's tenth problem
  3. 1988

    Unsolvability for a class of number-field rings

    first application

    Pheidas, T., Hilbert's tenth problem for a class of rings of algebraic integers, Proceedings of the American Mathematical Society, 1988

    Proves unsolvability for rings of integers of number fields with exactly one pair of complex embeddings, per Wikipedia.

    Dating or attribution note

    The restriction to one complex pair is per Wikipedia; the paper itself was not read.

    Evidence (2)
    • Hilbert's tenth problem for a class of rings of algebraic integers, Proc. AMS, 1988 Crossref record
    • Pheidas and Shlapentokh independently obtained the one-complex-pair case Wikipedia, Hilbert's tenth problem
  4. 1989

    Abelian number fields

    key development

    Shapiro, H. N., Shlapentokh, A., Diophantine relationships between algebraic number fields, Communications on Pure and Applied Mathematics, 1989

    Proves unsolvability over rings of integers of number fields whose Galois group over Q is abelian, using class field theory.

    Dating or attribution note

    The abelian statement is per Wikipedia; the paper was not read.

    Evidence (2)
    • Diophantine relationships between algebraic number fields, CPAM, 1989 Crossref record
    • Shapiro and Shlapentokh proved unsolvability for abelian number fields using class field theory Wikipedia, Hilbert's tenth problem
  5. 1993

    Matiyasevich publishes a monograph on Hilbert's tenth problem

    consolidation

    Matiyasevich, Y. V., Hilbert's tenth problem, 1993

    Book-length treatment of the undecidability of Diophantine equations, the basis for later ring-of-integer results.

    Dating or attribution note

    The book covers the general problem; whether it includes the rings-of-integers results was not checked.

    Evidence (1)
    • Open Library lists the book with first publication year 1993 Open Library works OL13330519W
  6. 2002

    Rank-one elliptic curves route

    key development

    Poonen, B., Using elliptic curves of rank one towards the undecidability of Hilbert's Tenth Problem over rings of algebraic integers, arXiv:math/0204001, 2002

    Proposes an elliptic-curve route using curves of rank one towards undecidability over rings of algebraic integers.

    Evidence (1)
    • Using elliptic curves of rank one towards the undecidability of Hilbert's Tenth Problem, arXiv 2002 arXiv listing (export.arxiv.org)
  7. 2024

    Koymans-Pagano claimed proof for all number fields

    key development

    Koymans, P., Pagano, C., Hilbert's tenth problem via additive combinatorics, arXiv:2412.01768, 2024

    Claims unsolvability over rings of integers of any number field, using additive combinatorics, which is the route the input summary describes.

    Dating or attribution note

    A preprint with a claimed proof. Peer-review status was not checked. A later arXiv version (2602.04468, 2026) exists for finitely generated rings and is not used as a separate milestone.

    Evidence (2)
    • Hilbert's tenth problem via additive combinatorics, arXiv posted December 2024 arXiv listing (export.arxiv.org)
    • Koymans and Pagano published a preprint with a claimed proof for any number field Wikipedia, Hilbert's tenth problem
  8. 2025

    Second independent proof

    key development

    Alpöge, L., Bhargava, M., Ho, W., Shnidman, A., Rank stability in quadratic extensions and Hilbert's tenth problem for the ring of integers of a number field, arXiv:2501.18774, 2025

    A second team that reportedly proves the same unsolvability result for rings of integers by different methods.

    Dating or attribution note

    Preprint status and the claimed scope were not verified from the text.

    Evidence (2)
    • Rank stability in quadratic extensions and Hilbert's tenth problem for the ring of integers of a number field, arXiv January 2025 arXiv listing (export.arxiv.org)
    • Another team proved the same result shortly after Koymans and Pagano using different methods Wikipedia, Hilbert's tenth problem
