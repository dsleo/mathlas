1949 · Numerical analysis

Monte Carlo method

Random sampling was used on computers to solve deterministic problems.

Also known as: Monte Carlo simulation

Locate this event on the map ↗

Historical record

These milestones show distinct stages of the idea. Dates and priority claims can be uncertain; consult the evidence and notes for each stage.

  1. 1930–1939

    Fermi's unpublished neutron-diffusion experiments

    precursor

    Enrico Fermi experimented with random sampling for neutron diffusion in the 1930s but did not publish it.

    Evidence (1)
    • Fermi experimented with the method in the 1930s and did not publish Wikipedia, Monte Carlo method (History)
  2. 1946

    Ulam's solitaire idea for neutron problems (private)

    precursor

    Ulam conceived random sampling for a neutron-diffusion problem in 1946 while convalescing; this was private thinking, not a publication.

    Evidence (1)
    • Ulam recounts that the first Monte Carlo thoughts came in 1946 from a solitaire question MacTutor, Stanislaw Ulam biography
  3. 1948

    ENIAC runs fully automated Monte Carlo fission-core calculation

    precursor

    In spring 1948 Monte Carlo calculations of a fission weapon core were run as fully automated computations on ENIAC.

    Evidence (1)
    • ENIAC performed the first fully automated Monte Carlo calculations of a fission weapon core in spring 1948 Wikipedia, Monte Carlo method (History)
  4. 1949

    Metropolis and Ulam, 'The Monte Carlo Method'

    first statement

    Metropolis N., Ulam S., The Monte Carlo method, Journal of the American Statistical Association 44(247), 335-341, 1949

    The first public description of the method as a named technique, in a journal article on random sampling for deterministic problems.

    Evidence (2)
    • Journal record: JASA 44(247), 335-341, September 1949 Crossref
    • MacTutor cites this 1949 paper as the method's description MacTutor, Stanislaw Ulam biography
  5. 1953

    Metropolis sampling rule for equilibrium calculations

    key development

    Metropolis N., Rosenbluth A. W., Rosenbluth M. N., Teller A. H., Teller E., Equation of state calculations by fast computing machines, J. Chem. Phys. 21(6), 1087-1092, 1953

    A Markov-chain sampling rule (later the Metropolis algorithm) was introduced, which made Monte Carlo a general tool for statistical mechanics.

    Evidence (1)
    • Crossref record: J. Chem. Phys. 21(6), 1087-1092, 1953 Crossref
  6. 1964

    Hammersley and Handscomb, Monte Carlo Methods

    consolidation

    Hammersley J. M., Handscomb D. C., Monte Carlo Methods, Methuen, 1964

    A book-length treatment of the method and its variance-reduction and sampling techniques.

    Dating or attribution note

    Priority as the first systematic book was not checked against earlier monographs.

    Evidence (1)
    • Open Library record: Monte Carlo methods, Methuen, 1964 Open Library
  7. Date unknown

    Name 'Monte Carlo' proposed as a code name

    naming

    Metropolis suggested the code name 'Monte Carlo' for the secret work of von Neumann and Ulam, after the casino.

    Evidence (1)
    • Metropolis suggested the code name; no year is given in the text checked Wikipedia, Monte Carlo method (History)
