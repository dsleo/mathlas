  1. 1928
    Game theory

    Strategic interaction is given a mathematical model, with minimax and equilibrium existence proved by convexity and fixed-point arguments.

    Combinatorial game theory (impartial and partisan games)

    Games assigned number values.

    Nash equilibrium: existence via fixed points

    Equilibria of non-cooperative games were shown to exist via fixed-point arguments.

  4. 2005
    Algorithmic game theory: complexity of Nash equilibria

    Equilibrium computation is classified in the class PPAD and used to analyse markets and auctions.
